# The Unwired — Coming Soon

A minimal black-and-white "coming soon" landing page for **The Unwired**.

## Files

- `index.html` — page structure and email form
- `style.css` — plain black-and-white styling
- `script.js` — placeholder (form submits directly via FormSubmit)

## Email form

Submissions are sent to **theunwired.in@gmail.com** via [FormSubmit.co](https://formsubmit.co).

The first submission will trigger a confirmation email from FormSubmit to verify the address. After confirming, submissions will arrive in the inbox.

## Customize

- Change the redirect URL in the `_next` hidden input.
- Update the page copy in `index.html`.

## Deploy

This is a static site with no build step. Deploy to GitHub Pages, Netlify, Vercel, Cloudflare Pages, or any static host.
