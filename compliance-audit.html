Compliance & audit

Evidence work, done before the audit window.

Most of a control test is collection. Pull the report, find the approval, match the ticket, capture the setting, file it with a reference. The judgement at the end takes minutes. The agent does the collection. A person signs.

All industries
01

Control evidence

Highest volume

Each control has a known list of evidence. The agent pulls it from the source systems on schedule and files it against the control, with a record of where it came from.

  • Evidence pulled on the schedule each control needs
  • Every artefact stored with its source and timestamp
  • Gaps flagged weeks before testing starts
02

Audit requests

Strong fit

The auditor's request list arrives as a spreadsheet. The agent maps each request to evidence already on file and drafts the response pack.

  • Requests matched to existing evidence before anyone goes searching
  • Missing items assigned to an owner with a due date
03

Access reviews

Strong fit

User access lists from every system, compared with HR records and role definitions. The agent builds the review. The system owner certifies it.

  • Leavers and role changes matched against active accounts
  • Exceptions listed for the owner to confirm or revoke
04

Policy and contract checks

Evidence work only

Reading documents against a requirement. Does this vendor contract have the clause? Does this policy cover the control? The agent finds and cites. A person decides.

  • Required clauses located and cited, or marked missing
  • Results recorded for the reviewer to accept or reject
01 How the agent works

The agent collects and cites. A person tests and signs.

1 The control is due

The schedule you already run on: monthly, quarterly, or when the auditor asks.

2 Evidence is collected

Reports, approvals, tickets and settings pulled from the source systems and filed against the control.

3 Gaps are flagged

Anything missing or out of pattern goes to its owner while there is still time to fix it.

4 A person signs

The tester reviews the pack and makes the call. The agent never concludes a control passed.
